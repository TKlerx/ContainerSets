# Contributing to Container Sets

Thank you for your interest in contributing to **Container Sets** 

Contributions are welcome, whether they are bug reports, feature requests,
documentation improvements, or code changes.

---

## 🛠️ Development Setup

- Firefox Desktop
- Basic knowledge of WebExtensions (MV3)
- JavaScript, HTML, CSS

Load the extension temporarily via:

`about:debugging` → *This Firefox* → *Load Temporary Add-on*

---

## 🧪 Testing

Please test your changes thoroughly:
- Context menu behavior
- Keyboard shortcuts
- Options page
- Internationalization (EN / DE)
- Duplicate tab handling
